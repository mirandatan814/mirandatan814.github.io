AI Skills for Researchers

Research workflows I've packaged as reusable agent skills — free for anyone to use and adapt.

The idea

A skill is a small, self-contained package that teaches an AI agent how to do one research task well. The convention is simple: a repo containing a SKILL.md file with the skill's name, what it's for, and step-by-step instructions the agent follows. Anyone can copy the repo and use it with their own AI assistant.

These are the workflows I kept rebuilding from scratch — so I packaged them once, properly.
